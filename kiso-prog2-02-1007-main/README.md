# 基礎プログラミングⅡ 後期第2回 デモコード

2026-10-07の授業で、スライドに出てきたコードをまとめたものです。

## ファイル

| ファイル | 内容 |
|---|---|
| 01-complement.c | 1111 1011 を符号付き（−5）と符号なし（251）で読む |
| 02-overflow.c | 符号付きcharの127に1を足すと−128になる |
| 03-if-score.c | if文で、60点以上なら10点、それ以外は0点 |
| 04-ternary-score.c | 03と同じ点数の決め方を三項演算子で書く |
| 05-pass-message.c | 三項演算子で表示する文字列だけを選ぶ |
| 06-max.c | 三項演算子で2つの数の大きい方を求める |
| 07-even-odd.c | 三項演算子で偶数・奇数を判定する |
| 08-usagi-kame-simple.c | 偶数はウサギ、奇数はカメを表示する（課題の出発点） |

## 実行方法

```
cc -Wall -std=c11 -o 01-complement 01-complement.c
./01-complement
```

## 注意

- 02-overflow.c の結果（−128）は、多くの環境での動作です。C言語の規格では、符号付きの範囲外の計算は未定義動作のため、環境によって結果が変わることがあります。
