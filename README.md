## 動作内容
- アルコールセンサで酒を飲んだか感知する
- ボタンはアルコールを感知しなくても発動するようにする裏コマンド的なやつ
- スピーカーはアルコールを感知したら音を出す
- サーボはアルコールを感知した時にその人の頬を叩く
